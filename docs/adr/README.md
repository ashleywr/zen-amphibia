# ADR Index

This folder stores Architecture Decision Records and other high-impact decision records.

Use ADRs when a decision needs more context than a short bullet in [DECISIONS.md](/C:/WorkDir/Minecraft%20Mods/Amphibia/docs/planning/DECISIONS.md).

## Naming

Use numbered markdown files:

- `0001-example-decision.md`
- `0002-example-decision.md`

## Suggested Template

```md
# 0001 Short Decision Title

## Status

Accepted

## Context

What problem or pressure caused this decision?

## Decision

What are we doing?

## Consequences

What does this enable, restrict, or require?

## Alternatives Considered

- Option A
- Option B
```

## Current Guidance

- Keep ADRs short
- Link relevant specs
- Do not duplicate whole spec documents here
- Use ADRs for durable why, not for every brainstorm
